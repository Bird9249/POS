# UI — Settings & Receipt Config

**ผู้ใช้:** Admin (Cashier เห็นแค่โปรไฟล์/ออกจากระบบ)

---

## โครงสร้างเมนูตั้งค่า

```text
ตั้งค่า
├─ ข้อมูลร้าน / ใบเสร็จ
├─ ผู้ใช้ (ถ้ารวมในแอป native)
├─ ขนาดใบเสร็จ (58mm / 80mm)
└─ เกี่ยวกับ / เวอร์ชันแอป
```

Online only สำหรับการบันทึก — ตอน Offline แสดงค่าที่ cache แบบอ่านอย่างเดียว + แบนเนอร์

---

## ฟอร์ม Receipt Configuration

| ฟิลด์ | UI |
| --- | --- |
| ชื่อร้าน | text |
| ที่อยู่ | textarea สั้น |
| เบอร์โทร | tel |
| Logo | เลือกภาพ + พรีวิว |
| เลขบัญชี | text |
| Static QR | อัปโหลดภาพ QR + พรีวิวใหญ่ |

Sticky: **บันทึก**

หลังบันทึกสำเร็จ → sync ลง local เพื่อใช้ตอนออฟไลน์บนหน้าโอนและใบเสร็จ

---

## พรีวิวใบเสร็จ
- บล็อกพรีวิวความกว้างจำลอง 58/80mm ในหน้าตั้งค่า
- แสดงชื่อร้าน, เบอร์, รายการจำลอง, วิธีชำระ, คำขอบคุณ

## โปรไฟล์ผู้ใช้ (ทุก Role)
- แสดงชื่อ + role
- เปลี่ยนรหัสผ่าน (ถ้ามี, online)
- ออกจากระบบ
