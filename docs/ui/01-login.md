## วัตถุประสงค์
เข้าสู่ระบบก่อนใช้งาน POS — **ต้องออนไลน์** เพื่อ login ครั้งแรก/refresh session

## Layout (Mobile)

```text
┌─────────────────────────┐
│                         │
│      ชื่อแอป / โลโก้      │
│                         │
│  [ ชื่อผู้ใช้ / อีเมล ]   │
│  [ รหัสผ่าน          ]   │
│                         │
│  [      เข้าสู่ระบบ     ]  │  ← ปุ่มเต็มแถว
│                         │
│  สถานะ: ออฟไลน์ (ถ้าเน็ตหลุด) │
└─────────────────────────┘
```

## พฤติกรรม
| สถานะ | UI |
| --- | --- |
| พร้อมกรอก | ปุ่มเข้าสู่ระบบ active เมื่อกรอกครบ |
| กำลัง login | ปุ่ม loading, กันกดซ้ำ |
| ผิดพลาด | ข้อความใต้ฟอร์ม (รหัสผิด / เน็ตหลุด) |
| Offline | ปิดปุ่ม login หรือแสดงว่าต้องเชื่อมเน็ต — **ไม่ให้เข้า checkout โดยไม่มี session** (ยกเว้นนโยบาย session ค้างจาก phase 7) |

## หลัง login สำเร็จ
- Admin → ไป `/checkout` (หรือ `/products` ถ้าต้องการ — ค่าเริ่มแนะนำ = Checkout)
- Cashier → `/checkout`
- ถ้ายังไม่เปิดกะ (Phase 6) → แสดง sheet/หน้าสั้นให้เปิดกะก่อนขาย
