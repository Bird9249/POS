# UI — Checkout (หน้าหลัก)

หน้านี้สำคัญที่สุด — ออกแบบให้จบการขายด้วยนิ้วมือน้อยครั้งที่สุด

## Layout หลัก

```text
┌─────────────────────────┐
│ ขาย          ● ออฟไลน์ 2 │  ← sync badge ถ้ามีบิลค้าง
├─────────────────────────┤
│ 🔍 ค้นหา / สแกน…         │  ← autofocus ตลอดเมื่อไม่เปิด modal
├─────────────────────────┤
│ ผลค้นหา (เมื่อพิมพ์)      │  ← list สั้น ชื่อ · ราคา · สต็อก
├─────────────────────────┤
│ ตะกร้า                   │
│ ─────────────────────   │
│ สินค้า A     − 2 +   ✕  │
│ 12,000 ₭   ส่วนลด       │
│ สินค้า B     − 1 +   ✕  │
│ …                       │
├─────────────────────────┤
│ ส่วนลดบิล (ถ้ามี)         │
│ รวม        45,000 ₭     │  ← ตัวใหญ่
│ [      ชำระเงิน       ]  │
├─────────────────────────┤
│ ขาย | สินค้า | รายงาน | … │
└─────────────────────────┘
```

## ส่วนประกอบ

### 1) ช่องค้นหา / สแกน
- Placeholder: ค้นหาชื่อ, รหัส, หรือยิงบาร์โค้ด
- Enter / จบสแกน → เพิ่มเข้าตะกร้าทันที ถ้าเจอ 1 รายการ
- ไม่เจอ → toast/banner สี danger: ไม่พบสินค้า
- ผลลัพธ์แสดงชื่อ, ราคาขาย, สต็อก (ไม่โชว์ทุน)

### 2) แถวตะกร้า
แต่ละแถว:
- ชื่อสินค้า (truncate)
- ปุ่ม − / จำนวน / +
- ราคาบรรทัด (หลังส่วนลดรายการ)
- เมนูหรือปุ่ม: ส่วนลดรายการ, ลบ

**ส่วนลดรายการ** — เปิด bottom sheet:
- เลือกประเภท: `%` หรือ `₭`
- ช่องตัวเลข + แป้นตัวเลขใหญ่
- แสดงยอดหลังลดสด

### 3) สรุปท้ายจอ (sticky)
- ยอดรวมใหญ่
- ปุ่ม **ชำระเงิน** เต็มแถว (disabled ถ้าตะกร้าว่าง)

## Flow ชำระเงิน (เต็มจอหรือ sheet สูง)

### ขั้นเลือกวิธี
```text
ยอดที่ต้องชำระ   45,000 ₭

[ เงินสด ]
[ โอนเงิน / BCEL One ]
```

### เงินสด
```text
ยอดที่ต้องชำระ   45,000 ₭
รับเงิน          [________]
เงินทอน          5,000 ₭     ← อัปเดตทันที, ตัวใหญ่

แป้นตัวเลข 0–9

[ ยืนยันรับเงิน ]   ← ปิดถ้าเงินรับ < ยอด
```

### โอนเงิน
```text
ยอดที่ต้องชำระ   45,000 ₭

┌─────────────┐
│  Static QR  │
└─────────────┘
บัญชี: xxx-x-xxxxx-x
ธนาคาร / BCEL One

[ ยืนยันว่าตรวจสลิปแล้ว ]
```

## หลังขายสำเร็จ
1. หน้าสำเร็จสั้น: ยอด, ทอน (ถ้ามี), ปุ่ม **พิมพ์ใบเสร็จ** / **ขายต่อ**
2. ล้างตะกร้าเมื่อกดขายต่อ
3. ถ้า Offline — แสดงว่าบิลอยู่ในคิวซิงก์

## สถานะพิเศษบน Checkout
| สถานะ | UI |
| --- | --- |
| ตะกร้าว่าง | ภาพว่างสั้น + ข้อความให้สแกน/ค้นหา |
| Offline | pill สี warning ที่ header — ยังขายได้ |
| มีบิลค้าง sync | ตัวเลขบน pill; แตะดูรายการคิว (optional) |
| สต็อก 0 | นโยบายล็อก: **เตือน (WARN)** ตอนเพิ่มลงตะกร้าเมื่อสต็อก ≤ 0 — ยังขายต่อได้ |
