# UI — Products, Categories, Stock

อ้างอิง: [02 Product & Inventory](../02-product-and-inventory.md) · [Phase 1–2](../phases/01-products-and-categories.md)  
**ผู้ใช้:** Admin เท่านั้น

---

## 1) รายการสินค้า

```text
┌─────────────────────────┐
│ สินค้า     [ซิงก์] [+]   │
├─────────────────────────┤
│ 🔍 ค้นหา                 │
│ Filter: หมวด · สต็อกต่ำ  │
├─────────────────────────┤
│ 🖼 ชื่อสินค้า            │
│    หมวด · สต็อก 12  ⚠    │
│    ขาย 10,000 ₭         │
│    ทุน 7,000 ₭          │  ← Admin only
└─────────────────────────┘
```

### พฤติกรรม
- แตะแถว → แก้ไข
- ปุ่ม `+` → สร้างสินค้า
- ป้าย ⚠ เมื่อ `stock_qty < min_stock`
- โหมดออฟไลน์: อ่านจาก local ได้; ปุ่มสร้าง/แก้ disabled พร้อมข้อความต้องออนไลน์ (ตาม architecture: เขียน online หลัก)

---

## 2) ฟอร์มสินค้า (เต็มจอ)

ฟิลด์เรียงตามความถี่ใช้:
1. ชื่อ
2. บาร์โค้ด (+ ปุ่มสแกนถ้ามี)
3. หมวดหมู่
4. ราคาขาย
5. ราคาทุน
6. สต็อกเริ่มต้น / คงเหลือ (แสดง)
7. Min stock
8. รูปภาพ

Sticky bottom: **บันทึก** · ลบ/ปิดใช้งานอยู่ในเมนูเพิ่มเติม (กันกดพลาด)

---

## 3) หมวดหมู่
- หน้ารายการสั้น: ชื่อ + จำนวนสินค้าในหมวด
- เพิ่ม/แก้/ลบ ผ่าน sheet หรือหน้าย่อย
- ใช้เป็น filter ในรายการสินค้าและ (อนาคต) checkout

---

## 4) ปรับสต็อก (Stock Adjustment)

```text
สินค้า: นม UHT
คงเหลือปัจจุบัน: 12

ประเภท: ( ) Restock  ( ) ปรับบวก  ( ) ปรับลบ
จำนวน: [____]
เหตุผล: [เสียหาย / หมดอายุ / รับเข้า / …]

[ ยืนยันปรับสต็อก ]
```

- Online only
- หลังสำเร็จ: อัปเดตรายการ + กระตุ้น sync ลงเครื่องอื่นผ่าน pull ครั้งถัดไป

---

## 5) Low Stock
- Filter เร็วบนหน้ารายการสินค้า
- หรือหน้าย่อย “สต็อกต่ำ” จากรายงาน/สินค้า — รายการเฉพาะที่ติดเกณฑ์
