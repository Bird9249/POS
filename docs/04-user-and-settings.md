# 4. ระบบจัดการผู้ใช้และการตั้งค่า (User & System Settings)

โมดูลควบคุมสิทธิ์ผู้ใช้ และการตั้งค่าข้อมูลร้าน/ใบเสร็จ

---

## 4.1 Role-based Access Control (2 Roles)

ระบบมี 2 บทบาทหลักเท่านั้นในระยะแรก

### Admin (เจ้าของร้าน)
ทำได้ทุกอย่างในระบบ รวมถึง:
- ดูรายงานทั้งหมด
- ดูราคาทุน / ต้นทุน
- เพิ่ม / แก้ไขสินค้าและสต็อก
- จัดการผู้ใช้และการตั้งค่าร้าน
- ดูยอดขายรวม

### Cashier (พนักงานขาย)
ทำได้เฉพาะงานขาย:
- คิดเงิน
- ออกใบเสร็จ
- ดูประวัติการขายของ **กะตนเอง**

ข้อจำกัดของ Cashier:
- **ไม่ให้เห็นต้นทุน (ราคาทุน)**
- **ไม่ให้เห็นรายงานยอดขายรวม**
- ไม่ควรเข้าถึงการตั้งค่าระบบระดับร้าน (ยกเว้นที่จำเป็นต่อการขาย)

### ตารางสิทธิ์สรุป

| ฟีเจอร์ | Admin | Cashier |
| --- | --- | --- |
| Checkout / ขายสินค้า | ได้ | ได้ |
| ออกใบเสร็จ | ได้ | ได้ |
| ดูประวัติขายของกะตนเอง | ได้ | ได้ |
| ดูรายงานยอดขายรวม | ได้ | ไม่ได้ |
| ดูราคาทุน / กำไร | ได้ | ไม่ได้ |
| จัดการสินค้าและสต็อก | ได้ | ไม่ได้ |
| ตั้งค่าใบเสร็จ / ข้อมูลร้าน | ได้ | ไม่ได้ |
| จัดการผู้ใช้ | ได้ | ไม่ได้ |

### ข้อกำหนดด้านความปลอดภัย
- Login แยกตามผู้ใช้
- ตรวจสิทธิ์ทั้งฝั่ง UI และ API
- Cashier ต้องไม่ดึงข้อมูลต้นทุนได้แม้เรียก API โดยตรง

## 4.2 Receipt Configuration

### วัตถุประสงค์
ตั้งค่าข้อมูลร้านที่จะแสดงบนใบเสร็จและหน้าชำระเงิน (เช่น QR โอน)

### ฟิลด์ที่ตั้งค่าได้

| ฟิลด์ | คำอธิบาย | ใช้ที่ |
| --- | --- | --- |
| ชื่อร้าน | ชื่อที่แสดงบนใบเสร็จ | ใบเสร็จ |
| ที่อยู่ | ที่อยู่ร้าน | ใบเสร็จ |
| เบอร์โทร | เบอร์ติดต่อ | ใบเสร็จ |
| Logo | โลโก้ร้าน | ใบเสร็จ (ถ้าเครื่องพิมพ์รองรับ) |
| เลขบัญชีธนาคาร | บัญชีรับโอน | ใบเสร็จ / หน้าโอนเงิน |
| Static QR Code | QR บัญชีร้าน (BCEL One ฯลฯ) | หน้าชำระแบบโอน |

### กฎธุรกิจ
- มีชุดค่าคอนฟิกระดับร้าน (store-level) ชุดเดียวในระยะแรก
- การเปลี่ยนค่ามีผลกับใบเสร็จใหม่ทันที
- ใบเสร็จเก่าไม่จำเป็นต้องอัปเดตย้อนหลัง

---

## ข้อมูลผู้ใช้ (แนะนำ)

| ฟิลด์ | คำอธิบาย |
| --- | --- |
| `name` | ชื่อผู้ใช้ |
| `username` / `email` | ใช้เข้าสู่ระบบ |
| `password` | รหัสผ่าน (เข้ารหัส) |
| `role` | `admin` หรือ `cashier` |
| `is_active` | เปิด/ปิดการใช้งาน |

---

## สิทธิ์ผู้ใช้ในโมดูลนี้
| การกระทำ | Admin | Cashier |
| --- | --- | --- |
| จัดการผู้ใช้ | ได้ | ไม่ได้ |
| เปลี่ยน Role | ได้ | ไม่ได้ |
| ตั้งค่าใบเสร็จ / ข้อมูลร้าน | ได้ | ไม่ได้ |
| แก้ไขโปรไฟล์ตนเอง | ได้ | ได้ (จำกัด) |

## เกณฑ์สำเร็จ (Acceptance Criteria)
- [ ] มี Role Admin และ Cashier ตามตารางสิทธิ์
- [ ] Cashier ไม่เห็นต้นทุนและรายงานยอดขายรวม
- [ ] Admin ตั้งค่าชื่อร้าน, ที่อยู่, เบอร์โทร, Logo, เลขบัญชีได้
- [ ] ข้อมูลตั้งค่าถูกนำไปแสดงบนใบเสร็จและหน้าโอนเงิน
