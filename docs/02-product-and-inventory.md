# 2. ระบบจัดการสินค้าและสต็อก (Product & Inventory)

โมดูลสำหรับจัดการข้อมูลสินค้า หมวดหมู่ สต็อกคงเหลือ และการแจ้งเตือนสต็อกต่ำ

---

## 2.1 Product Catalog

### วัตถุประสงค์
ดูแลรายการสินค้าทั้งหมดของร้าน

### ความสามารถ
- **เพิ่ม** สินค้าใหม่
- **แก้ไข** ข้อมูลสินค้า
- **ลบ** สินค้า (หรือปิดใช้งาน — แนะนำ soft delete เพื่อไม่ทำลายประวัติขาย)

### ฟิลด์สินค้า

| ฟิลด์ | บังคับ | คำอธิบาย |
| --- | --- | --- |
| `name` | ใช่ | ชื่อสินค้า |
| `image` | ไม่ | รูปสินค้า |
| `barcode` | ไม่* | บาร์โค้ด (*แนะนำให้มีถ้าใช้สแกน) |
| `cost_price` | ใช่ | ราคาทุน |
| `sell_price` | ใช่ | ราคาขาย |
| `category_id` | ไม่ | หมวดหมู่ |
| `stock_qty` | ใช่ | จำนวนคงเหลือปัจจุบัน |
| `min_stock` | ไม่ | เกณฑ์แจ้งเตือนสต็อกต่ำ |

### Category
- จัดกลุ่ม / หมวดหมู่สินค้า
- รองรับ เพิ่ม / แก้ไข / ลบ หมวดหมู่
- ใช้ช่วยกรองสินค้าในแคตตาล็อกและหน้า Checkout

### กฎธุรกิจ
- `sell_price` ควร ≥ 0
- `cost_price` ควร ≥ 0 (เห็นได้เฉพาะ Admin)
- `barcode` ควรไม่ซ้ำในระบบ
- สินค้าที่เคยมีประวัติขาย ไม่ควรลบจริงแบบถาวรโดยไม่มีการป้องกัน

---

## 2.2 Stock Tracking

### ตัดสต็อกอัตโนมัติเมื่อขาย
- เมื่อการขายสำเร็จ ระบบตัดสต็อกทันทีตามจำนวนที่ขาย

```text
stock_qty ใหม่ = stock_qty เดิม − จำนวนที่ขาย
```

### Stock Adjustment
ใช้เมื่อต้องปรับสต็อกนอกเหนือจากการขาย

| ประเภท | ใช้เมื่อ | ผลต่อสต็อก |
| --- | --- | --- |
| **Restock** | รับของเข้าคลัง / สั่งของมาเพิ่ม | เพิ่ม |
| **ปรับบวก** | นับของแล้วพบว่ามีมากกว่าในระบบ | เพิ่ม |
| **ปรับลบ** | ของเสียหาย / หมดอายุ / ของหาย | ลด |

### ข้อมูลที่ควรบันทึกทุกครั้งที่ปรับสต็อก
| ฟิลด์ | คำอธิบาย |
| --- | --- |
| `product_id` | สินค้าที่ปรับ |
| `type` | restock / increase / decrease |
| `quantity` | จำนวนที่ปรับ |
| `reason` | เหตุผล (เสียหาย, หมดอายุ, รับเข้า ฯลฯ) |
| `adjusted_by` | ผู้ปรับ |
| `adjusted_at` | วันเวลา |

### กฎธุรกิจ
- การปรับลบต้องไม่ทำให้สต็อกติดลบ (หรืออนุญาตตามนโยบายร้าน — ต้องกำหนดให้ชัด)
- ทุกการเปลี่ยนแปลงสต็อกควรมีประวัติย้อนหลังได้

---

## 2.3 Low Stock Alert

### วัตถุประสงค์
เตือนเมื่อสินค้าเหลือน้อย เพื่อช่วยตัดสินใจสั่งของเพิ่ม

### เงื่อนไข
```text
ถ้า stock_qty < min_stock → แสดงสถานะแจ้งเตือน
```

### การแสดงผล
- ไฟ / สัญลักษณ์เตือนบนรายการสินค้า
- อาจมีหน้ารวมสินค้า Low Stock สำหรับ Admin

### กฎธุรกิจ
- `min_stock` ตั้งได้ต่อสินค้า
- ถ้าไม่ได้ตั้ง `min_stock` อาจไม่ต้องแจ้งเตือน หรือใช้ค่าเริ่มต้นของระบบ

---

## สิทธิ์ผู้ใช้
| การกระทำ | Admin | Cashier |
| --- | --- | --- |
| ดูรายการสินค้า / ราคาขาย | ได้ | ได้ (ในหน้าขาย) |
| ดูราคาทุน | ได้ | ไม่ได้ |
| เพิ่ม/แก้ไข/ลบสินค้า | ได้ | ไม่ได้ |
| ปรับสต็อก | ได้ | ไม่ได้* |
| ดู Low Stock Alert | ได้ | ไม่จำเป็น |

> *ถ้าต้องการให้ Cashier ทำ Restock ได้ ให้กำหนดเพิ่มในภายหลัง

## เกณฑ์สำเร็จ (Acceptance Criteria)
- [ ] เพิ่ม/แก้ไข/ลบสินค้าได้ พร้อมฟิลด์หลักครบ
- [ ] จัดหมวดหมู่สินค้าได้
- [ ] ขายสำเร็จแล้วตัดสต็อกทันที
- [ ] Restock และปรับบวก/ลบสต็อกได้ พร้อมเหตุผล
- [ ] แสดงแจ้งเตือนเมื่อสต็อกต่ำกว่า Min Stock Threshold
