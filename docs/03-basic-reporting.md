# 3. ระบบรายงานพื้นฐาน (Basic Reporting)

โมดูลรายงานสำหรับเจ้าของร้านใช้ดูยอดขาย กำไร สินค้าขายดี และปิดกะ

---

## 3.1 Daily Sales Summary

### วัตถุประสงค์
สรุปยอดขายประจำวัน เพื่อรู้ว่าร้านขายได้เท่าไรในแต่ละวัน

### ข้อมูลที่แสดง
- ยอดขายรวมของวัน
- จำนวนบิล / จำนวนรายการ
- แยกตามวิธีชำระ:
  - **เงินสด (Cash)**
  - **เงินโอน (Transfer)**

### ตัวอย่างมุมมอง

| รายการ | ค่า |
| --- | --- |
| ยอดขายรวม | xxx กีบ |
| ยอดเงินสด | xxx กีบ |
| ยอดเงินโอน | xxx กีบ |
| จำนวนบิล | n |

### ตัวกรอง
- เลือกวันที่ (ค่าเริ่มต้น = วันนี้)
- (ถ้ามีหลายสาขาในอนาคต) เลือกสาขา

---

## 3.2 Profit & Loss Report

### วัตถุประสงค์
ดูกำไรขั้นต้นอย่างง่าย จากส่วนต่างราคาขายกับราคาทุน

### สูตร

```text
Gross Profit = (ราคาขาย - ราคาทุน) × จำนวนที่ขาย
```

### ขอบเขตระยะแรก
- คำนวณ **Gross Profit** แบบง่าย
- ยังไม่จำเป็นต้องมีค่าใช้จ่ายอื่น (ค่าเช่า, เงินเดือน ฯลฯ) ในรายงานนี้

### ข้อมูลที่ควรแสดง
| รายการ | คำอธิบาย |
| --- | --- |
| ยอดขายรวม (Revenue) | ผลรวมราคาขายสุทธิ |
| ต้นทุนรวม (COGS) | ผลรวมราคาทุน × จำนวนที่ขาย |
| กำไรขั้นต้น (Gross Profit) | Revenue − COGS |
| อัตรากำไร (ถ้าต้องการ) | Gross Profit / Revenue × 100 |

### สิทธิ์
- เห็นได้เฉพาะ **Admin** (Cashier ห้ามเห็นต้นทุนและรายงานยอดขายรวม)

---

## 3.3 Top Selling Products

### วัตถุประสงค์
ช่วยตัดสินใจสั่งของเพิ่ม จากสินค้าที่ขายดี

### ความสามารถ
- แสดงอันดับสินค้าขายดี **5–10 อันดับ**
- เรียงตามจำนวนที่ขาย หรือยอดขาย (กำหนดให้ชัดใน implementation)

### คอลัมน์ที่แนะนำ
| คอลัมน์ | คำอธิบาย |
| --- | --- |
| อันดับ | 1–10 |
| ชื่อสินค้า | ชื่อ |
| จำนวนที่ขาย | ชิ้น |
| ยอดขาย | กีบ |
| สต็อกคงเหลือ | เพื่อประกอบการสั่งของ |

### ตัวกรอง
- ช่วงวันที่ (วันนี้ / 7 วัน / 30 วัน / กำหนดเอง)

---

## 3.4 Shift / End of Day Closing

### วัตถุประสงค์
ปิดกะหรือปิดวัน เพื่อตรวจยอดเงินสดในลิ้นชักให้ตรงกับระบบ

### ประเภทรายงาน

| รายงาน | ความหมาย |
| --- | --- |
| **X-Report** | สรุปยอดระหว่างกะ / ตรวจเช็คระหว่างวัน โดยยังไม่ปิดกะถาวร |
| **Z-Report** | สรุปยอดตอนปิดกะ/ปิดวัน ใช้ปิดยอดอย่างเป็นทางการ |

### ข้อมูลที่ควรมีตอนปิดกะ
- ยอดขายรวมในกะ
- ยอดเงินสดที่ระบบคาดว่าควรมีในลิ้นชัก
- ยอดเงินโอน
- จำนวนบิล
- (แนะนำ) ยอดเงินสดที่นับได้จริง + ส่วนต่าง

### Flow แนะนำ
```text
1. เปิดกะ (ถ้ามีระบบกะ)
2. ขายระหว่างกะ
3. พิมพ์/ดู X-Report เพื่อตรวจระหว่างวัน (ถ้าต้องการ)
4. นับเงินสดในลิ้นชัก
5. ปิดกะด้วย Z-Report
```

## เกณฑ์สำเร็จ (Acceptance Criteria)
- [ ] ดูยอดขายรายวัน แยกเงินสด vs เงินโอนได้
- [ ] คำนวณ Gross Profit จาก (ราคาขาย − ราคาทุน) × จำนวน ได้ถูกต้อง
- [ ] แสดง Top 5–10 สินค้าขายดีได้
- [ ] มี X-Report / Z-Report สำหรับตรวจยอดเงินสดตอนปิดกะ
